# Skill manager test fixtures

Twenty small, harmless agent skills (one folder each under `skills/`, a `SKILL.md` and nothing else), used by
[Agent Skills Hub](https://agentskillshub.top/best/skill-management-tools/) to test skill managers end to end:
install them, list them, remove most of them, sync the rest to another agent.

They are fixtures, not a skill collection to use: each one is a short generic instruction file written for the test.

- The test and its results: https://github.com/zhuyansen/agent-skills-hub/tree/main/ops/skillmgr-runs
- The companion fixture with a risky setup script: https://github.com/zhuyansen/skill-manager-test-risky-fixture
